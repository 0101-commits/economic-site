### 1.2 네이버 개편의 핵심 원칙 (실측 근거)

1. **자산군으로 분류한다 — 출처로 분류하지 않는다.** 구버전의 「유가·금시세 › 국내·국제 유가」, 「원자재 › 에너지 선물」, 「원자재 › 비철금속 현물」은 신버전에서 **「시장지표 › 에너지」·「시장지표 › 금속」** 한 곳으로 합쳐졌다. 사용자는 "선물이냐 현물이냐"가 아니라 "기름값이 얼마냐"를 묻는다. (서비스 안내 탭4 전문)
2. **첫 화면은 답, 그 아래는 탐색.** 홈 1440 문서 높이 **4,994px**인데 첫 화면에는 장상태 띠 → 지수 카드 12 → 큰 차트 + 시장현황/투자자 패널 → AI 브리핑만 둔다. 랭킹·산업·리서치·지표 타일은 스크롤 아래.
3. **극단값 목록을 걷어냈다.** 상한가·하한가·급등·급락·장외시세·조건검색·공매도 거래 현황을 **제공하지 않는다**(탭2 「제공하지 않는 메뉴 안내」). 거래대금·시가총액·인기 중심으로 재편하고 세부는 종목 상세로 내려보냈다.
4. **개인 영역은 페이지가 아니라 상시 레일.** 우측 56px 레일(최근 본·보유·관심·내 피드·알림·캘린더·테마) + 312px 펼침 패널. 어느 페이지에 있어도 접근된다.
5. **시각(as-of)을 물건마다 붙인다.** `실시간` / `10분 지연` / `15분지연` / `장마감` / `2026. 9. 9. 기준 (장마감)` 배지가 값 옆에 항상 있다.
6. **AI 산출물에는 면책을 붙인다.** 「AI 요약 참고 자료이며, 기술적 오류로 실제 내용과 다를 수 있습니다」 + 베타 공지 하단의 긴 고지.

## 4. 설계

### C1 — IA: 자산군 축 재편 (P0)

좌측 레일을 **7항목 1뎁스**로 줄이고, 페이지 안에 **LNB 2뎁스**를 둔다.

| 신규 1뎁스 | LNB 2뎁스 | 현행 출처 |
|---|---|---|
| **홈** | — | `dashboard` |
| **국내주식** | 지수 · 랭킹 · 투자자 · ETF | `equity` 분할 |
| **해외·글로벌** | 미국 · 아시아 | `equity` 분할 |
| **시장지표** | 환율 · 채권·금리 · 에너지 · 금속 · 농축산물 · 운송 | **`market`(환율)** + `commodities` + `yieldCurve` + `freight` |
| **거시경제** | 경기 · 물가 · 고용 · 통화 · 무역 · 소비 | `macro` 14카드 → 6뎁스, `investor`(연기금) → 통화 하위 |
| **부동산** | 가격 · 대출 · 거래 · 공급 | `realestate` |
| **MY** | 투자현황 · 캘린더 · 노트 · 스터디 · 메르 | `portfolio`+`calendar`+`notes`+`study`+**`merblog` 흡수** |

`settings`는 레일에서 빼고 앱바 아이콘으로만 둔다.

**네이버 IA 실측 대조** (`.omc/research/naver-benchmark/IA-TREE.md`) — GNB **9** / LNB **49**(국내 12 · 미국·글로벌 8 · 시장지표 7 · 뉴스 7 · 리서치 7 · 가상자산 4 · 토론 2 · MY 2 · 홈 0) / 3뎁스 진입점 **11**(경로 세그먼트 9 + 쿼리 2). 종목 상세는 트리 밖 엔티티 페이지이고 자체 탭을 가져 **사실상 4뎁스**(`/domestic/stock/<코드>/info/finance`).

두 가지가 이 표를 고쳤다.

1. **시장지표 LNB는 6개다** — 환율 · 채권·금리 · 에너지 · 금속 · **농축산물** · **운송**(`/market/marketindex/transport`). 초안은 4개로 잡았는데 근거를 덜 읽은 탓이었고, 우리는 두 항목 모두 데이터를 이미 갖고 있다: 농축산물 = `commodities`의 Wheat·Corn·Soybean·Rice·Coffee·Sugar·Cocoa **7종**, 운송 = `freight.items` **9종**(SCFI 등 해운 운임) + `lmeInventory`. 현재 이 데이터는 화면에서 거의 드러나지 않는다.
2. **해외는 「미국」과 「글로벌」이 분리돼 있고, 글로벌은 지수 전용이다.** 미국 LNB 5(홈·실시간 랭킹·ETF·배당·업종), 글로벌 LNB 3(홈·실시간 랭킹·업종). 글로벌 홈 안에는 8탭(주요지표·중국·홍콩·일본·베트남·유럽·아시아·남미)이 있는데 **유럽·아시아·남미에는 종목 랭킹 테이블이 없고 지수 카드만 붙는다.** 개별 종목 데이터가 없는 시장을 어떻게 다루는지에 대한 답이며, 그게 정확히 우리 상황이다 — 우리는 `indices`에 SP500·NASDAQ·SOX·Nikkei·Shanghai만 있다. 그래서 LNB를 「미국 · 아시아」 2개로 두고 유럽·남미는 지수 자체가 없어 만들지 않는다.

**3뎁스 방식은 두 가지다** — 경로 세그먼트(`/stocklist/priceTop`, `/industry/1`, `/sector/UPBIT`)와 쿼리(`?tab=exchange-rate`, `?page=N`). 우리 라우팅은 이미 쿼리(`?p=`)이므로 3뎁스는 쿼리 확장(`?p=marketindex&t=fx`)으로 맞추고, 앵커(`#`)는 리서치 홈처럼 **URL을 바꾸지 않는 페이지 내 점프**에만 쓴다.

**URL 호환은 하드 요구사항이다.** `showPage(id)` / `?p=<id>`가 현재 링크·북마크·디스코드 알림 딥링크의 주소다. 구 id 12종을 **별칭 표로 살린다**:

```
?p=market      → 시장지표 > 환율        (?p=marketindex#fx)
?p=equity      → 국내주식 > 지수
?p=investor    → 거시경제 > 통화 #nps
?p=merblog     → MY > 메르
?p=dashboard/macro/realestate/portfolio/calendar/notes/study/settings → 동명 유지
```

별칭은 **리다이렉트가 아니라 해석**이다(히스토리를 더럽히지 않는다). 신규 URL도 병행 발급하고, 구 URL 진입 시 콘솔 경고 없이 조용히 새 화면을 연다.

**LNB 규격** (네이버 계측을 우리 격자에 맞춰 축소): 폭 196 → **176**, `position: sticky; top: 계산값`(앱바 56 + 서브바), 항목 높이 34, radius 6, pitch 44, 활성 배경 = 브랜드 blue 틴트(네이버의 초록 틴트 대응). 그룹 구분은 12px 추가 간격. 좌측 240 레일 안에 **중첩하지 않는다** — 1뎁스 레일은 그대로 240, LNB는 본문 1200 안쪽 좌측에 붙는다(본문 실효 폭 1200 − 176 − 24 = 1000).

### C4 — MY 우측 레일 (P3)

**56px 상시 레일 + 312px 펼침 패널.** 항목: 최근 본 / 관심 / 투자현황 / 캘린더 / (하단) 테마 토글.

- 로그인이 없으므로 「최근 본」·「관심」은 **localStorage**. 네이버의 「내 피드」·「알림」은 계정 기능이라 **비채택**.
- **PIN 잠금은 패널 내부에서만 걸린다** — 레일 아이콘은 항상 보이고, 투자현황 패널을 펼칠 때 PIN을 묻는다(현행 `sessionStorage.econLockOk_v1` 유지).
**레일은 본문을 밀어내지 않는다.** 초안은 「본문 폭을 56 줄인다(1200→1144)」라고 썼는데 실측은 다르다 (`MY-CALENDAR.md` §1):

```
sidePanelWrap  x1072 y65  368×835   position: fixed · z-index: 100
 ├ panelExpand x1072      312×835   플라이아웃 — 본문 위에 얹힌다(오버레이)
 └ sideMenu    x1384       56×835   아이콘 스트립 — 항상 노출, 이쪽만 레이아웃 폭을 차지
패널 내부 실효 콘텐츠 폭 ≈ 287
아이콘 48×59 ×6, 간격 0 · 테마 토글은 최하단에 372px 떨어져 분리
패널 헤더 sticky top:0 z:2 h=102 — 1행 제목+›, 2행 정렬 드롭다운 + 「원화로 보기」 체크토글
```

따라서 우리도 **아이콘 스트립 56px만 폭을 차지하고(본문 1200 → 1144), 펼침 패널 312px는 오버레이**로 덮는다. 좁은 화면에서 본문이 두 번 깎이는 일이 없다.

빈 상태 패턴도 그대로 가져온다 — padding `48px 24px`, 메인 16px/600, 서브 14px/400 회색, 행동 버튼 125×44. 우리는 로그인이 없으니 문구만 바꾼다(「로그인해 보세요」 → 「관심 종목을 추가해 보세요」).

한 가지는 **따르지 않는다**: 네이버는 `/my`(보유 종목)에 들어가도 레일이 여전히 「관심 종목」 탭을 활성으로 두어 URL과 레일이 연동되지 않는다(스크린샷 확인). 우리는 레일 항목과 현재 화면을 연동한다.

**표 설정의 규모는 화면마다 다르다** — 국내 랭킹표는 체크박스 55개, 보유 종목표는 컬럼 24개(종목명·금융기관·평가금액·평가손익·손익비교·보유수량·평균단가·매입금액·현재가·전일대비·거래대금·거래량·시가·고가·저가·매수호가·매도호가·외국인비율·상장주식수·시가총액·보통주배당금·PER·PBR·유보율). 우리 표는 열이 4~12개이므로 프리셋 칩만 채택한다.

**캘린더 (P3에 포함)** — 레일 6번째 아이콘 → 플라이아웃(전체화면 아님). 실측 구조:

| 요소 | 네이버 실측 | 우리 대응 |
|---|---|---|
| 헤더 | 제목 + ⓘ + 「✓ MY 종목만」 체크박스 (공지 삽화의 「시가총액 상위 종목 ▾」 드롭다운 서술은 실제 구현과 다르다) | 「내 관심 항목만」 체크 |

| 요일 격자 | **월~토 6열 — 일요일 칸이 아예 없다** | 채택 (D9 해소와 맞물린다) |

### C5 — as-of 배지 체계 (P2)

배지 4종을 **단일 컴포넌트**로. 값을 렌더하는 모든 곳이 이걸 쓴다.

| 배지 | 조건 | 표기 |
|---|---|---|
| `실시간` | 소스가 실시간이고 나이 ≤ 임계 | 초록 점 + 「실시간」 |
| `N분 지연` | 지연 공시 소스(원자재 등) | 회색 점 + 「10분 지연」 |
| `장마감` | 장 종료 후 마지막 값 | 회색 + 「09.09 15:30 장마감」 |
| `stale` | 나이 > 임계 | 주황 + 「N시간 전」 |

기존 `_tossChipHtml()`의 규칙(**LIVE에서는 침묵**)을 이 컴포넌트의 기본값으로 승격한다 — 항상 켜진 배지는 경고가 아니게 된다. 좌측 레일의 소스 표시등 13개와 「⚠ 지연 6 · 누락 1」은 **설정 > 시스템 진단으로 이동**하고, 홈에는 값 옆 배지만 남긴다.

### C6 — 토큰 정합 (P4)

- 스케일 밖 font-size 제거: **10px** · **13px** · **22px** · **13.3333px** · **32px** → xs11 / sm12 / base14 / lg18 / xl20 / 2xl24 로 흡수. `13.3333px`은 상속된 브라우저 기본값(16px×0.833)이 새는 지점이라 원인 규칙을 찾아 없앤다.
- 행 높이 36px 유지. 네이버 45/55를 따르지 않는다.
- 새 컴포넌트(지수 카드·지표 타일·랭킹 행·as-of 배지·LNB)는 `.econ-*` 로 정의하고 `--seed-*` 를 직접 참조한다. 그 외는 `--color-*`/`--c-*` 경유.
- 등락색: 텍스트 800 / 도형·스파크라인 700(`--c-up-fill`/`--c-down-fill`). 네이버 `#ED3738`/`#007EFF`를 **가져오지 않는다** — 우리 팔레트가 이미 한국 관습을 따른다.

## 8. 비고

- 네이버 화면을 **베끼는 것이 목적이 아니다.** 우리가 가져오는 것은 (a) 자산군 분류 원칙, (b) 첫 화면/탐색 분리, (c) 개인 영역을 레일로, (d) as-of를 값 옆에, (e) 극단값 목록을 만들지 않는 절제 — 다섯 가지다. 픽셀·색·행 높이·글자 크기는 우리 SEED 체계가 이긴다.
- 데이터가 없는 기능은 만들지 않는다. 「리서치」·「토론」·「미국 개별종목」을 빈 껍데기로 두는 것이 없는 것보다 나쁘다.
- **초안(2026-09-09 1차)의 오류 두 건을 이 문서가 고쳤다.** 근거를 덜 읽고 쓴 결과였다.
  1. 시장지표 LNB를 4개로 잡았다 → 실측 6개(농축산물·운송 누락). 우리는 두 항목 데이터를 이미 갖고 있었다.
  2. 우측 레일이 본문 폭을 줄인다고 썼다 → 실측은 아이콘 56만 폭을 차지하고 펼침 312는 오버레이다.
  덧붙여 해외 LNB를 「미국·아시아·유럽」으로 잡았으나 유럽 지수는 우리에게 없어 「미국·아시아」로 줄였고, 진단 D9(캘린더 요일 색)·D10(미노출 보유 데이터)이 새로 확인됐다.
- **남은 미확인** — 네이버 원시 자료가 전부 비로그인 수집이라 관심·보유 패널의 로그인 후 실제 DOM, 「관심」·「보유」 배지, 실적·배당 카드의 지표 행, 레일 접힘 상태 좌표는 확인하지 못했다. 우리 설계는 이 네 가지에 의존하지 않는다(전부 비채택 또는 데이터 없음 항목).
