# economic-site UX/UI 개편 설계 — Npay 증권 신버전 벤치마크

**작성** 2026-09-09 · **대상** `economic-site` (한국 경제 대시보드) · **기준** Npay 증권 PC 신버전(`stock.naver.com`)

---

## 1. 배경

네이버 증권이 PC 서비스를 전면 개편했다. **기존 증권 서비스는 2026-09-10 종료**되고 `stock.naver.com`의 「Npay 증권」으로 대체된다. 이 개편은 단순 리스킨이 아니라 **정보 구조(IA)의 재분류**이며, 그 재분류 원칙이 우리 사이트의 현재 문제와 정확히 겹친다.

### 1.2 네이버 개편의 핵심 원칙 (실측 근거)

1. **자산군으로 분류한다 — 출처로 분류하지 않는다.** 구버전의 「유가·금시세 › 국내·국제 유가」, 「원자재 › 에너지 선물」, 「원자재 › 비철금속 현물」은 신버전에서 **「시장지표 › 에너지」·「시장지표 › 금속」** 한 곳으로 합쳐졌다. 사용자는 "선물이냐 현물이냐"가 아니라 "기름값이 얼마냐"를 묻는다. (서비스 안내 탭4 전문)
2. **첫 화면은 답, 그 아래는 탐색.** 홈 1440 문서 높이 **4,994px**인데 첫 화면에는 장상태 띠 → 지수 카드 12 → 큰 차트 + 시장현황/투자자 패널 → AI 브리핑만 둔다. 랭킹·산업·리서치·지표 타일은 스크롤 아래.
3. **극단값 목록을 걷어냈다.** 상한가·하한가·급등·급락·장외시세·조건검색·공매도 거래 현황을 **제공하지 않는다**(탭2 「제공하지 않는 메뉴 안내」). 거래대금·시가총액·인기 중심으로 재편하고 세부는 종목 상세로 내려보냈다.
4. **개인 영역은 페이지가 아니라 상시 레일.** 우측 56px 레일(최근 본·보유·관심·내 피드·알림·캘린더·테마) + 312px 펼침 패널. 어느 페이지에 있어도 접근된다.
5. **시각(as-of)을 물건마다 붙인다.** `실시간` / `10분 지연` / `15분지연` / `장마감` / `2026. 9. 9. 기준 (장마감)` 배지가 값 옆에 항상 있다.
6. **AI 산출물에는 면책을 붙인다.** 「AI 요약 참고 자료이며, 기술적 오류로 실제 내용과 다를 수 있습니다」 + 베타 공지 하단의 긴 고지.

### 2.2 유지할 강점

- **표 행 높이 36px** — 네이버 45~55px보다 밀집하다. CLAUDE.md 규칙 3(「dense data renders as rows」)의 결과이고, 화면당 정보량이 우리가 더 많다. 네이버를 따라 키우지 않는다.
- **위젯 기본 접힘 + 390 높이 1,583px** — SEED P5의 성과. 이번 개편이 이 수치를 되돌리면 실패다.
- **SEED 브리지 단일 색 원천** · 등락색 2단(텍스트 800 / 도형 700) · 라이트·다크 두 테마.

## 4. 설계

### C1 — IA: 자산군 축 재편 (P0)

좌측 레일을 **7항목 1뎁스**로 줄이고, 페이지 안에 **LNB 2뎁스**를 둔다.

| 신규 1뎁스 | LNB 2뎁스 | 현행 출처 |
|---|---|---|
| **홈** | — | `dashboard` |
| **국내주식** | 지수 · 랭킹 · 투자자 · ETF | `equity` 분할 |
| **해외·글로벌** | 미국 · 아시아 · 유럽 | `equity` 분할 |
| **시장지표** | 환율 · 에너지 · 금속 · 채권·금리 | **`market`(환율)** + `commodities` + `yieldCurve` |
| **거시경제** | 경기 · 물가 · 고용 · 통화 · 무역 · 소비 | `macro` 14카드 → 6뎁스, `investor`(연기금) → 통화 하위 |
| **부동산** | 가격 · 대출 · 거래 · 공급 | `realestate` |
| **MY** | 투자현황 · 캘린더 · 노트 · 스터디 · 메르 | `portfolio`+`calendar`+`notes`+`study`+**`merblog` 흡수** |

`settings`는 레일에서 빼고 앱바 아이콘으로만 둔다.

**URL 호환은 하드 요구사항이다.** `showPage(id)` / `?p=<id>`가 현재 링크·북마크·디스코드 알림 딥링크의 주소다. 구 id 12종을 **별칭 표로 살린다**:

```
?p=market      → 시장지표 > 환율        (?p=marketindex#fx)
?p=equity      → 국내주식 > 지수
?p=investor    → 거시경제 > 통화 #nps
?p=merblog     → MY > 메르
?p=dashboard/macro/realestate/portfolio/calendar/notes/study/settings → 동명 유지
```

별칭은 **리다이렉트가 아니라 해석**이다(히스토리를 더럽히지 않는다). 신규 URL도 병행 발급하고, 구 URL 진입 시 콘솔 경고 없이 조용히 새 화면을 연다.

**LNB 규격** (네이버 계측을 우리 격자에 맞춰 축소): 폭 196 → **176**, `position: sticky; top: 계산값`(앱바 56 + 서브바), 항목 높이 34, radius 6, pitch 44, 활성 배경 = 브랜드 blue 틴트(네이버의 초록 틴트 대응). 그룹 구분은 12px 추가 간격. 좌측 240 레일 안에 **중첩하지 않는다** — 1뎁스 레일은 그대로 240, LNB는 본문 1200 안쪽 좌측에 붙는다(본문 실효 폭 1200 − 176 − 24 = 1000).

### C2 — 홈: 하이브리드 (P1)

**첫 화면 고정 영역 (≈900px, 1440 기준)**

| 순서 | 블록 | 데이터 | 비고 |
|---|---|---|---|
| 1 | 장상태 띠 | `marketCalendarKr` + 시각 | 「국내 KRX 정규장 09:00~15:30 · 미국 장마감 · 원자재 10분 지연」 |
| 2 | 지수 카드 스트립 (가로 스크롤) | `indices` 7 + `fx` 5 + 주요 `commodities` | 카드 = 이름 + as-of 배지 + 값 + 등락 + 스파크라인(`history`). 네이버 180×87 → 우리 격자 **176×84**, 12장, 좌우 화살표 |
| 3 | 큰 차트 + 우측 패널 | `history.indices` / `investorTrading` / `sentiment` | 좌 시장 차트, 우 「시장 현황」(52주 최저·최고 슬라이더 + VKOSPI·Fear&Greed) + 「투자자 정보」(외국인·기관·개인) |
| 4 | AI 브리핑 | `aiBriefing.lines` | 현행 「오늘의 매크로 3줄 요약」(253px)을 네이버 배치로 이동 + **면책 문구 명시** |

**아래 롱스크롤 (기본 접힘 + 점프 네비)**

5. **실시간 랭킹 4열** — 국내 거래대금(`rankingsKr.tradingAmount`) / 개인 순매수(`rankingsKr.tossAmount`) / 등락 Top(`stockMovers`) / ETF(`etfMovers`). 프리셋 칩으로 전환.
6. **지표 타일 12** — `fx` + `commodities` + `yieldCurve`, 2행×6, 타일 = 이름 + as-of 배지 + 값 + 등락 + 스파크라인. 네이버 216×91 → 우리 **192×84**.
7. **캘린더 요약** — 이번 주 `economicCalendar.events`(stars 필터) + `subscription`(청약) + 휴장.
8. **뉴스** — 현행 유지(탭 5).

점프 네비 = 첫 화면 하단에 `sticky` 섹션 앵커 칩. 접힘 상태는 기존 위젯 접기(`.w-toggle-btn` + `aria-expanded`)를 그대로 쓴다.

**게이트: 390 첫 화면 높이는 1,583px를 넘기지 않는다.** 롱스크롤 섹션은 390에서 전부 기본 접힘.

### C3 — 상세 3열 (P5)

종목·지수·지표 상세를 네이버식 3열로. 현재 우리에겐 종목 상세가 없고 `equity`의 Top10 행이 **네이버 종목 페이지로 이탈**한다(「종목 클릭 → 네이버 증권」). 이걸 자체 화면으로 되돌린다.

```
좌 300 sticky   현재가 · 등락 · as-of · 52주 레인지 · 시세정보 · 투자정보
중앙 나머지     큰 차트(기간·비교) · 투자자별 매매동향(stockFlows)
우 280          공매도·신용·대차·프로그램 칩 + 경고 배지(stockFlows.items)
```

`stockFlows`가 이미 관심종목 단위로 investor/short/credit/lending/program/warnings를 담고 있어 우측 패널이 채워진다. 네이버의 호가·시세 체결표는 **데이터가 없어 비채택**.

### C4 — MY 우측 레일 (P3)

**56px 상시 레일 + 312px 펼침 패널.** 항목: 최근 본 / 관심 / 투자현황 / 캘린더 / (하단) 테마 토글.

- 로그인이 없으므로 「최근 본」·「관심」은 **localStorage**. 네이버의 「내 피드」·「알림」은 계정 기능이라 **비채택**.
- **PIN 잠금은 패널 내부에서만 걸린다** — 레일 아이콘은 항상 보이고, 투자현황 패널을 펼칠 때 PIN을 묻는다(현행 `sessionStorage.econLockOk_v1` 유지).
- 레일은 `position: fixed`, 본문 폭을 56 줄인다(1200 → 1144). 좌측 240 + 본문 1144 + 레일 56 = 1440.

### C5 — as-of 배지 체계 (P2)

배지 4종을 **단일 컴포넌트**로. 값을 렌더하는 모든 곳이 이걸 쓴다.

| 배지 | 조건 | 표기 |
|---|---|---|
| `실시간` | 소스가 실시간이고 나이 ≤ 임계 | 초록 점 + 「실시간」 |
| `N분 지연` | 지연 공시 소스(원자재 등) | 회색 점 + 「10분 지연」 |
| `장마감` | 장 종료 후 마지막 값 | 회색 + 「09.09 15:30 장마감」 |
| `stale` | 나이 > 임계 | 주황 + 「N시간 전」 |

기존 `_tossChipHtml()`의 규칙(**LIVE에서는 침묵**)을 이 컴포넌트의 기본값으로 승격한다 — 항상 켜진 배지는 경고가 아니게 된다. 좌측 레일의 소스 표시등 13개와 「⚠ 지연 6 · 누락 1」은 **설정 > 시스템 진단으로 이동**하고, 홈에는 값 옆 배지만 남긴다.

### C6 — 토큰 정합 (P4)

- 스케일 밖 font-size 제거: **10px** · **13px** · **22px** · **13.3333px** · **32px** → xs11 / sm12 / base14 / lg18 / xl20 / 2xl24 로 흡수. `13.3333px`은 상속된 브라우저 기본값(16px×0.833)이 새는 지점이라 원인 규칙을 찾아 없앤다.
- 행 높이 36px 유지. 네이버 45/55를 따르지 않는다.
- 새 컴포넌트(지수 카드·지표 타일·랭킹 행·as-of 배지·LNB)는 `.econ-*` 로 정의하고 `--seed-*` 를 직접 참조한다. 그 외는 `--color-*`/`--c-*` 경유.
- 등락색: 텍스트 800 / 도형·스파크라인 700(`--c-up-fill`/`--c-down-fill`). 네이버 `#ED3738`/`#007EFF`를 **가져오지 않는다** — 우리 팔레트가 이미 한국 관습을 따른다.

## 8. 비고

- 네이버 화면을 **베끼는 것이 목적이 아니다.** 우리가 가져오는 것은 (a) 자산군 분류 원칙, (b) 첫 화면/탐색 분리, (c) 개인 영역을 레일로, (d) as-of를 값 옆에, (e) 극단값 목록을 만들지 않는 절제 — 다섯 가지다. 픽셀·색·행 높이·글자 크기는 우리 SEED 체계가 이긴다.
- 데이터가 없는 기능은 만들지 않는다. 「리서치」·「토론」·「미국 개별종목」을 빈 껍데기로 두는 것이 없는 것보다 나쁘다.
