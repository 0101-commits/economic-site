# 디스코드 버튼 방향 이모지 — 설계 스펙

- 날짜: 2026-08-15
- 대상 repo: `economic-site` (한국 경제 대시보드)
- 요청: 디스코드 알림의 부문별 링크 버튼을 "이미지/색/차트"로 꾸미는 요구 → 디스코드 네이티브 버튼 제약 내에서 **방향 이모지**로 방향·강도를 시각화. **카카오 경로는 제외, 디스코드에만 적용.**

## 1. 목표 / 비목표

**목표**
- 디스코드 알림 버튼 라벨에 등락 방향 이모지(`📈/📉/⏫/⏬/➖`)를 붙여, 스캔 없이 방향·강도가 읽히게 한다.
- 기존 기획(`c661d5b0` 버튼 그리드, 카드 이미지, 웹훅 폴백)의 구조·도달 보장은 **전혀 건드리지 않는다.**
- 적용 지점: 다이제스트 그리드, 마감 리포트 내비게이션, 급변 속보, 시장중단 경보. 유틸 행은 이모지 보강.

**비목표 (YAGNI)**
- 네이티브 버튼 색상/스타일 커스텀 — 디스코드 제약(링크 버튼은 회색 고정, 5종 스타일만 존재)으로 불가. 이모지로 대체.
- 버튼 위 차트/배경 이미지 — 디스코드 제약(버튼에 이미지 불가)으로 불가. 카드 이미지 + 라벨 이모지로 근사.
- embed 본문 이미지를 클릭 링크로 — 디스코드 제약(embed 이미지 클릭 = 확대보기, 이동 없음)으로 불가. 제목/작성자/버튼/텍스트 하이퍼링크만 이동함.
- **카카오톡 발송 경로 변경** — 사용자 명시 제약. `kakao.send_memo` 및 카카오 메시지 형식 무변경.
- `check_alerts.py` 종목 알림 버튼 — 라벨에 등락률이 없어 방향 데이터가 없음(별도 스펙에서 다룰 수 있으나 이번 범위 아님).

## 2. 배경 — 디스코드 제약 (확정)

| 요구 | 제약 | 대안 |
|------|------|------|
| 부문 이미지를 클릭 → 링크 | embed `image` 클릭은 확대보기만, 이동 없음 | 네이티브 링크 버튼(기존 그리드) 유지 |
| 버튼에 색/차트/배경 이미지 | 버튼 스타일 5종 고정, 이미지 불가 | **방향 이모지**로 방향·강도 표현 |
| 버튼당 커스텀 색 | 링크 버튼은 항상 회색(2) 고정 | 이모지로 구분 |
| (추가) 버튼에 `emoji` 필드 | 웹훅 버튼엔 emoji 필드 없음 | **라벨 문자열 안에 이모지 포함** → 봇 경로·웹훅 폴백 모두 그대로 전달 |

- 버튼 한계: 최대 5행 × 5열(25개), 라벨 80자 — 현 구조(16+유틸)에서 여유 있음.
- 웹훅 폴백(봇 토큰 없음): `notify_discord`가 링크 버튼을 "바로가기" embed 필드로 자동 변환 — **라벨(이모지 포함)이 필드 값으로 이어지므로 폴백에도 이모지 유지**.

## 3. 이모지 매핑 (공통 헬퍼)

기존 E2 강도 표준(`_dc_intensity`, ±2% 임계)과 일치시킨다. 등락률 → 이모지:

| 조건 | 이모지 | 의미 |
|------|--------|------|
| `c is None` | `➖` | 데이터 없음 |
| `abs(c) < 0.05` | `➖` | 보합 |
| `c >= +2.0` | `⏫` | 강한 상승 |
| `c <= -2.0` | `⏬` | 강한 하락 |
| `c > 0` | `📈` | 상승 |
| 그 외 | `📉` | 하락 |

- 신규 헬퍼 `notify_discord.direction_emoji(c)` — `send_kakao_digest`/`check_swings`/`check_halts`가 모두 이미 `notify_discord`를 import하므로 공통 헬퍼 위치로 적합. 단일 정의·단일 유지.

### 라벨 형식 (일관 규칙)
- 등락 있음: `{emoji} {이름} {등락률:+.1f}%` — 예 `📈 코스피 +1.8%`, `⏬ S&P500 -2.4%`
- 등락 없음: `{emoji} {이름}` — 예 `➖ 구리`
- 기존 `▲/▼` 텍스트는 이모지로 대체(중복 제거). 퍼센트는 `:+.1f`(부호 포함)로 표기.

```

  _dc_button_rows / _send_close_report nav / check_swings._btns / check_halts._halt_buttons

        │
        ├─ 봇 토큰 있음 ──▶ 네이티브 링크 버튼 (라벨에 이모지 표시)
        └─ 봇 토큰 없음 ──▶ "바로가기" embed 필드 (라벨=이모지 포함, 도달 유지)
```

## 6. 검증 (완료 기준)

1. `python scripts/send_kakao_digest.py` 테스트 모드(또는 `workflow_dispatch`)로 디스코드에 다이제스트·마감 리포트 발송 → 버튼 라벨에 이모지 표시 확인.
2. 테스트용 급변/시장중단 이벤트로 `check_swings`/`check_halts` 버튼 이모지 확인.
3. 웹훅 폴백 경로: 봇 토큰 없는 환경(`DISCORD_*` 웹훅만)에서 폴백 필드에 이모지 포함 확인.
4. `c=None`(구리·밀·옥수수 등 네이버 미제공) → `➖`로 렌더, 행 배열 4열 유지.
5. ±2% 이상 지표(코스피 급락 등) → `⏫/⏬`, 그 외 `📈/📉` 임계 동작 확인.

## 7. 리스크 / 오픈 이슈

- **라벨 길이**: 이모지+이름+퍼센트(~15자) ≪ 80자 제한 — 영향 없음.
- **이모지 렌더 폰트**: 구형 클라이언트에서 `⏫/⏬` 미지원 가능 → `📈/📉` 폴백은 자연 발생(텍스트로 폴백). `➖`는 보편 지원.
- **행/열 배치**: 라벨 길이 변화로 그리드 균형이 미세히 달라질 수 있으나 개수·URL 무변경이라 배열은 동일.
- **카카오 무영향**: 변경 전부 디스코드 전용 라벨이므로 카카오 메시지/버튼과 완전 분리 (사용자 제약 충족).
